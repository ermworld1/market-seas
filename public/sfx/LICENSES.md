# Sound effect licenses

Every file below comes from a source published under **CC0 1.0 (public domain dedication)**:
free for commercial use, no attribution required. Each file was trimmed, converted to mono
(ambience loops stay stereo), loudness-normalised and in some cases layered or echoed.
Machine-gun bursts were assembled from single CC0 shots. Torpedo files layer the CC0 launch
with a low-passed CC0 detonation.

Sounds with no suitable CC0 recording stay procedural (synthesised in the browser):
dive-bomber whistle, submarine dive/surface, fled, reinforce, cascade sting.
